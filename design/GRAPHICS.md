## 1. 方針

1. **承認済みの絵を変えない。** 4人の顔・目・肌・衣装の色はテクスチャのまま。光は乗算、被弾の白は一時的な混色だけ。新しい絵は描き足していない。
2. **演出は Core のイベントが原因。** 予備動作はイベントの表示開始から始まり、着弾は HP が変わる瞬間と同じフレーム。演出が順番・結果・時間を変えない。
3. **測るものを動かさない。** 足元 HP や重なり判定は `"Private approved static skin"` / `"Fixture slime"` の mesh と transform から計算されている。動きはすべてシェーダーの中で起こし、mesh・transform・bounds は静止時のまま。
4. **外部素材ゼロ。** エフェクトはテクスチャを使わず数式で描く。敵は実行時に作る mesh。追加の素材・有料アセット・外部サービスは無し。

## 3. キャラクター（味方4人）

### 3.1 パペットの仕組み

- 絵は 3:4 の板。その上に 20×28 のグリッド（609 頂点）を置き、各頂点は最大4本の骨に従う。重みは骨の線分からの距離のガウス関数で自動計算（骨ごとに半径と強さを指定）。
- 骨は画像空間（幅 0.75・高さ 1、足元が y≈0.08）の 2D アフィン変換。親子関係つき。GPU で合成するので mesh は変わらない。
- 骨は 11本: 体幹（Root / Body / Head）、武器（Weapon）、脚（LegL / LegR）、揺れもの（CapeL / CapeR / HairL / HairR / Extra）。脚の骨は定義だけ残し、どの動きでも動かしていない。
- 注意: この方式は1枚絵の変形なので、量を誤るとゴムのように見える。承認原画と同じ子に見えることが最優先で、違和感のある動きは量を下げるか外す（判断は Human の目視）。

| キャラ | 型 | Extra の使い道 | 揺れもの |
|---|---|---|---|
| シロ | 詠唱 | 帽子の先（立つばね） | 長い髪 左右、外套 左右 |
| モモ | 盾 | 盾（クリップで前へ出す） | 髪 左右、スカート 左右 |
| ガル | 剣 | — | 外套 左右 |
| ミャル | 弓 | 尾（ゆっくり大きく揺れるばね） | 髪 左右、葉の外套 |

骨の位置は承認絵を見て手で決めた値で、`HqPuppet.Authored(index)` にある。絵を差し替えたらここを直す。

### 3.2 揺れもの（二次運動）

髪・外套・尾・帽子の先は減衰ばね。入力は三つ:

- 親の骨の動き（体が左へ動けば先端は右へ遅れる）
- 上下の速さ（落ちるときに外へ開く）
- 風（遅い正弦波2つの和。全員少しずつ位相が違う）

硬さと減衰は骨ごと（尾は柔らかく遅い、帽子は硬い）。攻撃や詠唱のクリップは `flare` を出し、外套と髪が外へ開く。

### 3.3 動きの一覧

| 状態 | 中身 | 長さ |
|---|---|---|
| 待機 | 足元からの呼吸、体のゆっくりした揺れ、頭は一拍遅れる、武器がわずかに上下 | 常時 |
| 歩き（代用表現） | 体全体が一枚のまま左右の足へ交互に揺れ、小さく弾む。頭と武器が逆位相。足が着くたびに土ぼこり。**脚は曲げも伸ばしもしない**（脚のメッシュ変形は Human が「うにょうにょ」として不採用） | 移動中 |
| 攻撃（剣） | 肩へ担いで後ろに溜める → 踏み込んで振り抜く → 戻る | イベント長＋0.45秒 |
| 攻撃（盾／メイス） | 後ろへ振りかぶる → 上から叩く | 同上 |
| 攻撃（弓） | 体を引いて溜める → 放って前へ弾む、尾が遅れて振れる | 同上 |
| 攻撃（詠唱） | 力を集めて沈む → つま先立ちで杖を突き出す、髪と外套が開く | 同上 |
| 詠唱（回復） | 杖や手を上げて伸び上がる → 光が届いたら下ろす | イベント長＋0.36秒 |
| 守り | 足を踏ん張って沈む。モモは盾が前へ出て大きく見える | イベント長＋0.31秒 |
| 被弾 | 攻撃の来た向きへ向き直り、のけぞる。頭が一拍遅れ、3回揺れて戻る。白く光る | 0.7秒 |
| 回復を受ける | 軽く2回跳ねる。淡い緑に光る | 0.55秒 |
| 戦闘不能 | よろけて倒れ、上から光の粒になって消える | 0.72秒 |
| 勝利 | 立っている全員が跳ねる | 0.7秒 |

溜め（予備動作）は表示時間の 70%、振り抜きは残り 30% で、**振り抜きの終わりが着弾**。着弾の瞬間に 0.06 秒のヒットストップ（全員の姿勢が止まる）。

### 3.5 1枚絵の限界（知っておくこと）

- 骨の回転は ±1 rad 程度まで。それ以上は絵が伸びて歪む。大きな動きは体全体の傾き・伸び縮みとエフェクトで見せている。
- 武器と体が重なる部分（ガルの剣の柄と腕など）は一緒に曲がる。違和感が出ない範囲に抑えている。
- 向きは左右反転だけ。背面・横向きは無い。
- まばたき・表情の変化は無い（顔を描き変えないため）。§7 に提案。

## 4. エフェクト

### 4.1 仕組み

- CPU の粒プール（上限 3000）を毎フレーム 1つの mesh にして 1回で描く。Unity の ParticleSystem もテクスチャも使わない。
- 形は 12種（柔らかい光・輪・十字のきらめき・三日月の斬撃・流線・花びら／葉・十字（回復）・煙・結晶の欠片・守りの膜・魔法陣・光の柱）。フラグメントシェーダーの数式で描く。
- 「光」と「物質」を1パスで混在（前乗算）。遺跡が明るいので純加算は白飛びする。光は背景を 42% 覆ってから 78% 加える設定。
- 向き: 画面向き／地面に寝かせる／進行方向に沿わせる の3種。
- 一時停止で止まる。リセットで消える。

### 4.2 Core イベントとの対応

| Core イベント | 開始時（予備動作） | 着弾時（HP が変わる瞬間） |
|---|---|---|
| Damage: シロ | 足元に回る魔法陣と光の柱、杖先に光が集まる → 66% で光弾を放つ | 青の衝撃（閃光・輪・火花・欠片） |
| Damage: ミャル | 弓に光が集まる → 68% で矢を放つ（葉の尾を引く） | 緑の衝撃 |
| Damage: ガル | 74% で対象に三日月の斬撃 | 白銀の衝撃 |
| Damage: モモ | 72% でメイスの軌跡 | 桃色の衝撃 |
| Damage: 敵 | 縮んで溜める → 62% で体当たりの軌跡 | 敵の色の衝撃 |
| 守りで軽減された Damage | 同上 | 守りの膜が鳴り、欠片が散る。衝撃は 55% の大きさ。対象は水色に光る |
| Counter | 行動者の頭上に金の閃き、以降は Damage と同じ | 85% の大きさの衝撃 |
| Protect | 行動者が構える。30% で対象に守りの膜 | — |
| Heal | 行動者の足元に緑の魔法陣、光が集まる | 対象に緑の柱、十字ときらめきが昇る |
| Death（敵） | 膨らんで上から崩れる。45% で雲と種が弾ける | — |
| Death（味方） | 倒れて光になる。30% で花びらと光の柱が昇る | — |
| Move | 出発の土ぼこり、歩きの一歩ごとに土ぼこり。敵は2回跳ねる | — |
| End（勝利） | 花びらと金のきらめき、全員が跳ねる | — |

表示時間（`HqMotion.cs`）: Damage 0.62秒、Counter / Protect 0.50秒、Heal 0.60秒、Death 0.72秒、Move 0.52秒。着弾の後に 0.26秒の余韻。一撃はおよそ 0.9秒に収まる。

### 4.3 環境

盤の上を花びら（白・淡桃）が左下へ流れ、ときどき金の光の粒が昇る。0.22〜0.5秒に1つ。演出を減らす設定で止められるようにする（`HqVfx.Ambient`）。

## 5. 敵（庭の精）

- **体**: 従来と同じ mesh（縁が波打つ楕円体）。他のコードが測る対象なので形は変えていない。
- **陰影**: 2階調のトゥーン、下からの石の照り返し、上からの空色、縁の光、艶の点。主光の向きはフィールドと揃える。
- **顔**: カメラが上から見下ろすので、顔はカメラに向いた面に置く（水平に回し、上へ傾ける）。大きな縦長の目に光が2つ、頬紅、小さな口。
- **冠**: 苔の精は双葉の芽、花の精は五弁の花と葉。風で揺れる。
- **動き**: 呼吸の伸び縮み、まばたき（2〜5秒ごと）、溜めて跳びかかる、ぷるんと震える被弾、膨らんで崩れる消滅。すべてシェーダー内で足元を軸に変形する。

## 5.5 2026-11-16 の強化（戦闘の手応え）

実寸のコマを見直したところ、動きも光も小さく「何が起きたか」が伝わっていなかったため、次を入れた。作り方と数値の根拠は [CRAFT_HANDBOOK.md](CRAFT_HANDBOOK.md)。

| 追加 | 内容 |
|---|---|
| 踏み込み | 近接の味方（ガル、モモ）と敵は、攻撃で相手の体に重なる所まで進み、当ててから戻る。シェーダー内の移動で、pawn と矩形は動かない |
| 吹き飛び | 当てられた側は攻撃の向きへ飛ばされ、小さく浮いて戻る |
| 当たり | 暗い暈・放射線・二重の輪・火花と欠片。白い石の上でも光が見えるよう、暈を先に敷く |
| 斬撃・撃破 | 三日月を三重にし、撃破には放射線と大きな輪を追加 |
| 重い一撃 | モモの一撃と敵の体当たりは、床を走る輪と砂煙（`Slam`） |
| ダメージ数字 | これまで枠で切り落とされて表示されていなかったのを修正。大きさ 28、味方の被弾 = 赤、敵への攻撃 = 黄、反撃 = 金、回復 = 緑 |
