# 詳細設計 07 — 画面・カメラ・命中の見え方

- 版: 2026-11-17 / 作成: Claude Code / 状態: **未実装の設計**（§5 の光の調整だけ実装済み）
- 決定の出典: [DECISIONS.md](../DECISIONS.md) B2・B3・B5・B8。元の割り付けは [IMPLEMENTATION_SPECS.md §3〜4](../IMPLEMENTATION_SPECS.md)
- 根拠: 寸法は 390×844pt の割り付けと、Simulator（iPhone 17 Pro、402×874pt）で 2026-11-17 に見た画面からの見立てです。実装して画面で確かめるまで確定ではありません。

## 0. 考え方

- **盤が主役**。画面で一番広く、一番明るい。HUD は盤を囲む額縁で、盤に被せない。
- 画面に出す情報は、Core が持っているものだけ。Lv、スキルの列、2本目のゲージのような「絵としてそれらしい」部品は出さない。
- 主操作は親指の届く下 1/3。タップ領域は 44pt 以上。
- 正解を教えない。おすすめの印、色での優劣、警告以外の点滅を出さない。

## 1. 割り付け（B5: カードを詰めて盤を広げる）

いまの画面（Simulator で観察）: 上に遺跡名と「記録」、その下に状況の一行と「準備」の札、左に「階層」の帯、中央に盤、下にカード4枚（高さ約 145pt）、最下段に操作ボタン2つ。カードと操作で画面の下 30% を使っています。

| 帯 | いま（見立て） | 設計 | 中身 |
|---|---|---|---|
| 上端 | 約 70〜145pt | 54〜98pt（44pt） | 遺跡名（左）、階の表示「2F」（中）、記録（右） |
| 行動順 | 無し（左の「階層」帯が縦に占有） | 98〜132pt（34pt） | 行動順の帯。横一列 |
| 盤 | 約 160〜590pt | **132〜612pt（480pt、画面の 57%）** | 盤と景色 |
| 出来事の一行 | 上端の下にある | 612〜640pt（28pt） | いま演出しているイベントを1行 |
| カード | 約 610〜755pt（145pt） | **640〜756pt（116pt）** | 4枚。§1.1 |
| 主操作 | 約 765〜815pt | 760〜810pt（50pt） | §1.2 |

- 「階層」の縦の帯は無くし、上端の「2F」に畳む。探索中だけ小地図を盤の右下に出す（既存の `FloorMapGraphic`）。
- 数値は 844pt 基準。実機の高さとの差は盤の帯で吸収する（盤だけが伸び縮みする）。セーフエリアは既存の `ApplySafeArea` を通す。
- 完了条件: 390×844、402×874、375×667（小さい端末）の3つで、部品が互いに重ならず、盤が画面の 55% 以上。PlayMode の矩形の検査に3サイズを足す。

### 1.1 カード（116pt）

```
┌────────────┐
│ 顔（72pt）   [役割の印] │  上 72pt: 顔。右上に役割の印（盾・剣・十字・星）
│ シロ                    │  名前 13pt。顔の下端に重ねる
│ ████████░░  16/18       │  HP の棒 6pt と数字 12pt
│ 挟み撃ち                │  いまの一手（§3）。13pt。1行
└────────────┘
```

- いま名前の下にある「HP 16 / 16」の行と棒を1行にまとめ、29pt を盤に返す。
- HP の最大値は**戦闘の状態から読む**。いまのカードは `Fixture.Baseline().Find(id).MaxHp` を読んでいます（`HqProductHud.cs`）。部屋ごとの値や持ち越しを入れると食い違うので、`Session.Replay.State` から読むように直す。
- 棒の色は HP が 35% 以下で赤に変わる（既存）。色だけに頼らず、35% 以下では数字の横に「！」を出す。
- 倒れた仲間のカードは彩度を落とし、顔の上に「戦闘不能」。押せない。
- カードを押すと、その仲間に狙いを指定する修正（`TargetOnce`）の入口になる（既存の顔カードからの指示）。修正が残っていないときは押しても何も起きず、主操作の残数が 0.2 秒揺れる。

### 1.2 主操作

| 状態 | 左（幅 40%） | 右（幅 60%、金） |
|---|---|---|
| 戦闘前 | 方針（§2）。いまの方針名を表示 | 戦闘開始 |
| 戦闘中 | 早送り（1倍 / 2倍） | 一時停止 |
| 危機で停止 | 方針を変える（残り1） | このまま続ける |
| 戦闘後 | 戦闘を再試行 | 次へ進む（2回目以降は「予想と結果」を記録の中へ移す） |
| 探索中 | 小地図 | 守り手に挑む（部屋の前にいるとき） |

- 修正の残数は「方針を変える（残り1）」の括弧の中にだけ出す。出典は `Replay.CorrectionsLeft`。
- 危機で止まったとき、右を「このまま続ける」にして**金**にする。変えるのが正解に見えないようにするため。

## 2. 方針を選ぶ（B3）

戦闘前に左の主操作を押すと、盤の下から 3 択が上がる。

```
┌──────────┬──────────┬──────────┐
│  [盾]    │  [天秤]  │  [剣]    │
│  慎重    │ バランス │  攻める  │
│ いつも   │ シロが   │ 守らず   │
│ シロを守る│ 半分まで │ 敵へ向かう│
│          │ 減ったら守る│        │
└──────────┴──────────┴──────────┘
```

- 1階ではバランスを出さない（2択。[DECISIONS.md](../DECISIONS.md) N5）。2階に降りたとき、3つ目が増えたことを1行で知らせる（「モモが新しい戦い方を覚えた」）。説明は選択肢の中の2行だけ。
- 選んだ瞬間に、盤の上の矢印（意図）が新しい方針のものに描き変わる。これが方針の説明の本体です。文章で説明しない。
- 並び順は固定（慎重・バランス・攻める）。前回選んだものに印を付けない。
- 説明文は Core の定義（[01](01_CORE_RULES.md) §3）と一字一句対応させる。定義を変えたら文も直す。

## 3. 意図と「なぜその手か」（B8）

| 部品 | 中身 | 出典 |
|---|---|---|
| 矢印（次に動く者） | 太い実線。先端に行動の印（剣・盾・十字・足跡） | `Replay.Intents()` の先頭 |
| 矢印（その後） | 細い点線。印なし | `Replay.Intents()` の2番目以降 |
| カードの一言 | [01](01_CORE_RULES.md) §4 の表の日本語 | `Plan.Why` |
| 危機の「！」 | 倒れる恐れのある味方の頭上 | `Rules.Threatened` |
| 行動順の帯 | 顔の小さな丸を横一列。いまの行動者に金枠。倒れた者は詰める | `EncounterState.Initiative` と `Cursor` |

- 矢印は味方が青、敵が赤。色だけに頼らず、敵の矢印は先端を角ばらせる。
- 敵の一言は出さない。敵の狙いは矢印で読む（読むことが遊びなので）。
- 矢印は顔と足元の HP を横切らないよう、駒の縁から出して縁で止める。
- 一言は**現在の意図**です。先の手を予言しない（`Intents` は今の状態だけを読む、という Core の定義どおり）。
- 完了条件: 全員の矢印と一言が、同じ瞬間の `Replay.Intents()` と一致することを PlayMode で固定。

## 4. カメラ（B5: 戦闘中は寄せる）

いまの実装（`HqCamera.cs`、`MobileG1View.cs`）: 正射影。見える横幅は連戦時 18.75、それ以外 16（`HqFieldWidth`）。中心は `BattleCenter()`。距離 21、pitch と yaw は固定。カメラを動かす演出は無い。

| 状態 | 横幅 | 中心 | 変わり方 |
|---|---|---|---|
| 探索 | 18.75（現行） | 一行の重心 | — |
| 戦闘前（読む） | 15.0 | 盤の中心 | 部屋に入ってから 0.6 秒、ease-out |
| 戦闘中 | **13.5** | 生きている全員を含む矩形の中心。盤の中心から最大 1.0 まで | 一巡ごとに 0.5 秒で追う |
| 勝利 | 13.5 → 15.0 | 盤の中心 | 1.2 秒 |

- 13.5 にすると、キャラは連戦時（横幅 18.75）の 1.39 倍になる。横幅 16 のとき画面幅の約 14%（[IMPLEMENTATION_SPECS.md §3](../IMPLEMENTATION_SPECS.md) の値）なので、約 17% になる見込み（未計測）。
- **一撃ごとの寄りは入れない**。画面揺れを入れない（B13）のと同じ理由で、矩形の計算（`ProjectedBody`）と足元の HP が1コマごとに動き、検査が不安定になるため。寄りは「戦闘に入ったら寄る」「一巡ごとにゆっくり追う」だけ。
- **カメラが動いている間は一手を始めない**。寄りが終わってから演出の時間割（[CRAFT_HANDBOOK.md §2](../CRAFT_HANDBOOK.md)）を始める。これで「測るもの」の位置は一手の間ずっと動かない。
- 実装: `SetComparisonCamera` が毎回 `orthographicSize` と位置を直接書いている。横幅と中心を引数に取る `SetCamera(width, center)` に分け、状態ごとの目標へ補間する小さな更新を `LateUpdate` に置く。補間が終わったら `Refresh()` を1回。
- 「演出を減らす」では補間せず、一度に切り替える。
- **検査**: 既存の重なりの検査（`HqPresentationTests.CheckVisibleHealth`）を、横幅 18.75・15.0・13.5 の3つで通す。13.5 で盤の四隅の駒（(0,0)、(4,0)、(0,4)、(4,4)）が盤の帯（132〜612pt）からはみ出さないことを足す。はみ出すなら 13.5 を 14.0 に。
- 注意: 重なりの検査（[ROADMAP.md](../ROADMAP.md) S1-1、2026-11-18 解決）は顔が画素で隠れないかを見ます。寄せると顔どうしが近づくので、寄せた後も PlayMode で確かめてください。

## 5. 命中の白い光を弱める（B2）

2026-11-17 に Simulator で、着弾の瞬間に白い玉が対象をほぼ覆うコマを確認しました。これはグラフィック担当（Claude）の仕事で、次のとおり直します。

| 項目 | いま（`HqVfx.Impact`） | 直す先 |
|---|---|---|
| 中心の光（`Glow`） | 大きさ 0.5 → 1.5、0.12 秒 | 0.4 → 0.9、0.08 秒。透明度の上限を 0.6 に |
| きらめき（`Sparkle`） | 大きさ 1.7 → 0.8 | 1.2 → 0.6 |
| 放射線（`Burst`） | 役割によらず同じ強さ | 鈍器・敵 1.0、剣 0.3、魔法と矢 0（白い輪も鈍器だけ）。形（線・紋・細い筋）を主役にする（2026-11-18 に形での見分けへ変更。[CRAFT_HANDBOOK.md](../CRAFT_HANDBOOK.md) §5.3.1） |
| 暗い暈（`Veil`） | あり | そのまま（白い石の上で光を読ませるために要る） |

**2026-11-17 に実装済み**（表の「直す先」に加え、出だしの白い輪を細くした: `Ring` の `k0` .2 → .5、透明度 .8）。Unity 6000.3.25f1 で撮ったコマで、着弾の瞬間もシロとスライムが輪の中に見えることを確認。**2026-11-18**: 4種の見分けを形で作り分け、コマで4種とも確認（[ROADMAP.md](../ROADMAP.md) S1-2 の現状）。人が数字を隠して言い当てる確認は未実施。

- 完了条件: 着弾のコマで対象の輪郭と顔が見える。数字を隠した状態で、剣・鈍器・魔法・矢を見分けられる（[ROADMAP.md](../ROADMAP.md) S1-2）。
- 確かめ方: `RT_GFX_CAPTURE` のコマと Simulator の録画。直した数値と理由は [CRAFT_HANDBOOK.md §5](../CRAFT_HANDBOOK.md) の表に書き足す。

## 6. 文字と色

- 最小 12pt。主要な情報（名前、HP、一言、主操作）は 13pt 以上。主操作は 16pt。
- 縁取りと影を必ず付ける（空と石が明るく、白い文字が溶けるため）。既存の `HudPanelGraphic` の濃紺の板の上に置くのが基本。
- 色の意味を固定する: 味方 青、敵 赤、回復 緑、守り 金、危機 赤。同じ色を別の意味に使わない。
- 色だけで区別しない。形（丸と角）、印（盾・剣）、文字のどれかを必ず添える。
- 日本語の折り返しで1文字だけ次の行に落ちない幅にする。一言は全角8字まで、出来事の一行は全角18字まで。

## 7. 画面のつながり

| 切り替え | やること | 時間 |
|---|---|---|
| 探索 → 戦闘前 | カメラが寄る。カードが下から上がる。行動順の帯が出る | 0.6 秒 |
| 戦闘前 → 戦闘中 | 主操作が入れ替わる。矢印が次の一手だけ太くなる | 0.2 秒 |
| 戦闘中 → 危機 | 演出が止まる。対象に「！」。主操作が入れ替わる。環境音が沈む（[05](05_AUDIO.md)） | 0.3 秒 |
| 戦闘中 → 勝利 | カメラが引く。金の帯に結果。倒れた仲間が起き上がる（25% で戻る） | 1.2 秒 |
| 勝利 → 探索 | 帯が消える。カードの HP が「ひと息」の分だけ伸びる（数字を出す） | 0.8 秒 |
| 泉 | 水面の光。1人ずつ回復の数字 | 1.2 秒 |
| 報酬 | 盤の上に遺物2つ（[04](04_RELICS_AND_GEAR.md) §4） | 待つ |

- 白や黒で画面全体を覆う切り替えは使わない。盤はいつも見えている（探索と戦闘が同じ場で起きる、という確定事項のため）。
- 勝利の後の「ひと息」と復帰は、Core の `PartyState.AfterVictory` の結果を**数字つきで見せる**。黙って HP が増えていると、持ち越しの規則が読めない。

## 8. テスト

- 3つの画面サイズで部品の矩形が重ならない。盤が 55% 以上。
- 主操作が5つの状態で正しい文言と色になる。
- 方針の3択の説明文が Core の定義と対応している（定義の版が上がったら落ちる）。
- カメラの3つの横幅で `CheckVisibleHealth` が通る。カメラが動いている間に一手が始まらない。
- カードの HP の最大値が戦闘の状態と一致する（部屋ごとに敵味方の値が違っても）。
