# 総合設計 04 — 導入（最初の5分）

- 版: 2026-11-17 / 作成: Claude Code / 状態: **[提案]**。人で確かめていません
- 位置づけ: 初めての人が、説明を読まずに遊び方を掴むまでの設計。[GAME_DESIGN.md](../GAME_DESIGN.md) §3.3 の「チュートリアル無しの導入」の中身。
- 根拠: 1階の3戦の結果は既存テスト（`GauntletCoreTests`）と [sim/](../sim/README.md) の計算。「人がこう感じる」の部分はすべて仮説です。

## 0. 考え方

- **説明の画面を作らない。** 手を止めて文章を読ませない。
- **1階の3戦そのものが導入**です。既存の3戦は、偶然ではなく、次の順で学べる並びになっています（既存テストの名前がそれを示しています）。

| 戦い | 盤の性質（計算と既存テスト） | 学ぶこと |
|---|---|---|
| 1戦目 | 慎重なら全員生存。攻めるとシロが倒れる | 仲間は自分で動く。方針で結果が変わる |
| 2戦目 | 慎重のままだとシロが倒れる。攻めるなら全員生存。慎重で始めても、危機で攻めるに変えれば全員生存 | さっきの正解が通らない。危機で止まり、1回だけ変えられる |
| 3戦目 | どちらの方針でも誰か倒れる。攻めるで始めて危機で慎重に変えたときだけ全員生存。逆は悪化する | 修正は「何に変えるか」で結果が違う |

- 導入の間も、**正解は言わない**。言うのは「何ができるか」だけ。
- 失敗させてよい。1戦目でシロが倒れても遠征は続き、やり直しもできる。

## 1. 最初の画面

起動して最初に見えるのは、タイトル画面ではなく**盤**です。4人が遺跡に立っていて、敵が2体いる。

| 見せるもの | 見せないもの |
|---|---|
| 盤、4人、敵2体、足元の HP | 階の表示、小地図、記録、設定 |
| 全員の矢印（意図） | 行動順の帯（2戦目から） |
| 下に4人のカード | カードの一言（2戦目から） |
| 主操作は**右の金のボタン1つだけ**:「見守る」 | 方針の選択（1戦目の後から） |

- 1戦目は方針を選ばせません。モモは「慎重」で始まります。これが[禁止事項](01_EXPERIENCE.md)の唯一の例外です。理由: 最初の1手で二択を迫ると、何も分からないまま選ぶことになる。まず「任せると動く」を見せる。
- 主操作の文言は1戦目だけ「見守る」。2戦目から「戦闘開始」。
- 3秒間何も押されなければ、金のボタンがゆっくり1回だけ明滅する。それ以上の催促はしない。

## 2. 1戦目 — 任せると動く

| 起きること | 学び | 仕掛け |
|---|---|---|
| ボタンを押すと、仲間が矢印どおりに動く | 矢印は意図 | 最初の1手だけ、矢印が動きに変わる瞬間を 0.2 秒長く見せる |
| モモが盾を構え、シロへの一撃が軽くなる | 守りが効いた | 盾の光がモモから出る。数字の横に「−3」 |
| シロが反撃する、ガルが挟む、ミャルが癒やす | 4人が違うことをする | 型ごとの演出と音 |
| 全員生存で勝つ | 任せて勝てる | 勝利の帯。**褒める文言は出さない**（「勝利」だけ） |

勝った後、主操作が2つになります。左「もう一度」、右（金）「先へ進む」。

- ここで初めて左のボタンを押すと、**方針の選択が開く**（慎重／攻める）。「攻める」を選んでやり直すと、シロが倒れます。
- やり直すかどうかは任せます。やり直さずに進んだ人は、2戦目で同じことを学びます。
- 計算上、1戦目の演出は約 25 秒です。

## 3. 2戦目 — さっきの正解が通らない

2戦目の前に、主操作の左が「方針」になります。行動順の帯とカードの一言が出ます。

| 起きること | 学び | 仕掛け |
|---|---|---|
| 慎重のまま始める人が多い（1戦目で勝ったので） | — | 何も言わない |
| 17 手目で、シロが倒れそうになって**止まる** | 危機で止まる | 「！」、環境音が沈む。主操作が「方針を変える（残り1）」と「このまま続ける」に |
| 変える → 全員生存。続ける → シロが倒れる | 1回だけ変えられる。変えると結果が違う | 結果の違いは見せるだけ。「変えてよかった」とは言わない |

- 止まったときに出す文言は、事実の1行だけ:「シロが倒れそうだ」。
- 初めて止まったときに限り、2つのボタンの上に小さく1行:「戦いの途中で、一度だけ方針を変えられる」。**これが、ゲーム全体で唯一の説明文**です。2回目からは出しません。
- 攻めるで始めた人は、止まらずに全員生存で勝ちます。その人は3戦目で危機停止に出会います。

## 4. 3戦目 — 何に変えるかで違う

| 起きること | 学び | 仕掛け |
|---|---|---|
| どちらで始めても、14 手目で止まる | — | — |
| 慎重で始めて攻めるに変える → 悪化する（2人倒れる） | 変えれば良くなるとは限らない | 何も言わない |
| 攻めるで始めて慎重に変える → 全員生存 | 盤を読んで選ぶ | 何も言わない |

- ここで多くの人が誰かを倒れさせます。**それでよい。** 勝てば仲間は起き上がり、やり直しもできる。
- 3戦目の後、初めて「記録」が開けるようになります。開くと、いまの3戦の自分の選択と結果が並んでいる。説明はしない。

## 5. 見せる順番のまとめ

| 部品 | 出る時機 |
|---|---|
| 盤、矢印、カード、足元の HP、「見守る」 | 最初から |
| 「もう一度」と「先へ進む」 | 1戦目の後 |
| 方針の選択（2択） | 1戦目の後に「もう一度」を押したとき、または2戦目の前 |
| 行動順の帯、カードの一言 | 2戦目から |
| 危機停止と修正 | 最初に危機が来たとき |
| 記録 | 3戦目の後 |
| 探索（行き先を託す） | 1戦目と2戦目の間（部屋の間を歩く） |
| 階の表示、小地図 | 2戦目の後 |
| 予想メモ | 2階から。設定で最初から出せる |
| バランスの方針、HP の持ち越し | 2階 |
| 遺物 | 2階の終わり |
| 設定 | いつでも（右上の記録ボタンの長押し、または記録の中）。1戦目の間は入口を見せない |

- 2回目以降の遠征では、この順番を全部飛ばして、最初から全部出します（保存に「導入を終えた」の印を1つ持つ）。
- 設定に「導入をもう一度見る」を置く。

## 6. 言葉の決まり

- 導入で出す文は、上に書いたものだけです: 「見守る」「勝利」「もう一度」「先へ進む」「シロが倒れそうだ」「戦いの途中で、一度だけ方針を変えられる」「方針を変える（残り1）」「このまま続ける」。
- 命令形を使わない（「〜しよう」「〜してください」）。
- 仲間の名前は最初からカードに出す。役割の名前（守り手、支援など）は出さない。役割は動きで分かるようにする。
- 英語、専門用語（ターン、バフ、クールダウン）を使わない。

## 7. うまくいかなかったときの次の手

導入は、人で確かめるまで仮説です。[07](07_PLAYTEST.md) の S1 試遊で、次の兆候を見ます。

| 兆候 | 意味 | 次の手 |
|---|---|---|
| 最初の画面で 10 秒以上止まる | 何をすればよいか分からない | 明滅を早める。ボタンの文言を変える |
| 1戦目の後、何が起きたか説明できない | 演出が読めていない | 最初の3手だけ演出を遅くする（1.5 倍の長さ） |
| 危機で止まったことに気づかない | 止まり方が弱い | 画面の縁を暗くする。音を強める |
| 止まったとき、必ず「変える」を押す | 変えるのが正解だと読んでいる | 文言と色を見直す |
| 3戦目の後、「運ゲー」と言う | 因果が読めていない | 行動順の帯を1戦目から出す |
| 説明を探す（「ヘルプは？」） | 説明なしが成立していない | 記録の中に「遊び方」を1画面だけ置く（図と、6の言葉だけ） |

## 8. 実装の入口

- 導入の段階は Presentation の状態として持つ（`OnboardingStage { First, Second, Third, Done }`）。Core の規則には触れない。
- どの部品を出すかは §5 の表を1か所にまとめた対応表から引く。部品ごとに条件を散らさない。
- テスト: 段階ごとに、出ている部品が §5 のとおり。`Done` では全部出る。段階が Core の結果に影響しない（同じ入力で同じ hash）。
