# 戦闘視認性 v0

実装対象は承認済み `assets/accepted-mock.png` の縦一画面。比較ボードの見出しや注釈はゲーム画面に入れない。

- 暗紺 #192a39、文字 #edf4fa、境界 #405566。
- A 青 #71a5cf、敵 珊瑚 #f88d90、反撃 琥珀 #e9bf64、自力回復 青緑 #50d9c6、B支援 緑 #68e9b1。
- A 中央55%、HP直下、4目盛り小さく左右、B 下74%。敵は上半分。分割待機は右上。
- 文字: system-ui、日本語 sans-serif。操作14px以上、見出し16px。
- 再生中: 停止と速度のみ。停止/終了: 見返す、速度、シーク、構成変更、任意詳細。
- 構成変更は四条件と集中/分割を同格で選択。おすすめ、意図、AI、勝因解説はない。
- SVG図形は本試験で意図的に維持するモック用表現。製品アート制作は行わない。
- 初期配置、通常攻撃、被弾、反撃、吸血、B支援、死亡を確定イベントから描く。
- 初撃は各間隔経過後。待機敵は全体の1.8秒周期へ参加。ゲージ余剰持越し。回復判定は各攻撃イベント束の末尾。CD満了だけでは回復を発動しない。味方同時攻撃はA→後衛の順で毎回対象選択。待機敵の参加は束の完了後。
- 演出: 予備120ms別枠。被弾→反撃→吸血→支援は最大520ms。次イベント間隔へ圧縮。同じ再生時計で停止、0.5倍、シーク。
- ローカルのみ。外部サービス、永続学習、遠隔記録なし。
